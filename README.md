## PROYECTOS DESTACADOS
A continuación se presentan los proyectos realizados en Visual Studio Code:

### Liquidity & Risk Analytics Pipeline (Fintech Simulation) | Python + SQL
Diseñé e implementé un pipeline de datos end-to-end para análisis de liquidez y riesgo, simulando un entorno fintech.
- Construí procesos ETL y modelado de datos en PostgreSQL con vistas agregadas para análisis eficiente
- Desarrollé análisis de P&L, riesgo de liquidez y comportamiento de flujos de efectivo
- Implementé automatización de reportes y visualizaciones usando Python (pandas, matplotlib)
- Apliqué optimización de queries e indexación para mejorar rendimiento
- Generé insights sobre patrones de retiros, gaps de liquidez y desempeño de inversiones
  
### Modelo de Valor Relativo (ERP + Commodities) | Python
- Diseñé un sistema diario que calcula el Equity Risk Premium (Earnings Yield vs Bono USA 10y) y el ratio Oro/S&P 500 con ventana móvil de días.
- Implementé detección de outliers mediante Mediana de Desviaciones Absolutas (MAD) para validar cotizaciones.
- Generé reportes normativos (cierre de operaciones y Markdown con señales, alertas, etc.).
- Simulé operaciones de compra/venta respetando límites (40%-60% acciones).

### Backtesting de Estrategia para Criptomonedas | Python
- Analicé datos históricos obtenidos de Binance
- Calculé métricas de riesgo-rentabilidad (Sharpe ratio, drawdown máximo, rentabilidad anualizada, win rate)
- Evalué desempeño bajo diferentes condiciones de mercado
